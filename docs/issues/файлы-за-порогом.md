### `GitService` по заботам

- **Лог / коммиты** (`:334-590`, ~250 строк): `getCommitLog` ×2,
  `getOutgoingCommits`, `searchCommits`, `searchCommitLog`, `grepCommits`,
  `getCommitDiff` ×2, `getCommit`, плюс `resolveCommitId`, `treeIterator`,
  `messageBody` (`:1635`), `reportedPath` / `normalizedDiffPath` (`:1700-1714`).
  Самое очевидное продолжение `CommitSearch` — `CommitHistory`.
- **Рабочее дерево / изменения** (`:1313-1590`, ~280 строк):
  `getUncommittedChanges` ×4, `changes`, `status`, `statusOf`, `admits`,
  `untrackedDiffEntry`, `countLines`, `headTreeIterator` → `WorkingTreeChanges`.
- **Чтение файлов** (`:748-1015`, ~270 строк): `getFileContent` ×4,
  `getFileOutline*`, `getFileInfo`, `getFileBytes`, `getRawFile*`, `hashFile`,
  `readTrackedFile`, `readBytes`, `requireServableSize` → `FileReads` поверх
  `FileViews` / `RepoFiles` / `CommitFiles`.
- **Поиск по имени** (`:595-680`): `searchFiles`, `isTestPath`, `fuzzyScore` —
  самодостаточно, `FileNameSearch`.
- Уже тонкие делегаты, трогать не надо: дерево/browse, grep и blame
  (`GitGrepRunner` / `GitBlameRunner`), ветки и команды (`GitBranches` /
  `GitCommands`), правки (`GitWriter`).

Порядок: сначала `CommitHistory` (там же живёт пункт про `truncated` из
`списки-без-признака-обрезки.md`), потом `WorkingTreeChanges`. После двух
вынесений `GitService` под порогом.
