# Задачи после #449–#481

Ревизия кода после тридцати последних коммитов (#449–#481, 1.1.0 и после): где
улучшение, сделанное в одном коммите, ещё не применено в соседних местах, и что
после этих коммитов просится в реорганизацию. Один файл на категорию, внутри —
пункты по убыванию ценности, со ссылками `файл:строка` на момент ревизии.

| Файл | Из каких коммитов идея |
| --- | --- |
| [`списки-без-признака-обрезки.md`](списки-без-признака-обрезки.md) | #475, #477, #488, #492 — `truncated`, названный предел |
| [`git-подпроцесс.md`](git-подпроцесс.md) | #478, #481 — `GitReadProcess` |
| [`файлы-за-порогом.md`](файлы-за-порогом.md) | #475, #478, #487 — `CommitSearch`, `CodeView`, `Diffs` |
| [`blame.md`](blame.md) | #478, #483, #485, #490 — колонка blame и её соседи |
| [`логи-и-тесты.md`](логи-и-тесты.md) | #462, #463, #464 — `@SuppressWarnings`, PIT |

Каждый пункт — отдельный PR или часть PR, который и так трогает этот файл
(правило «migrate on touch» в `CLAUDE.md`). Закрытый пункт удаляется из файла,
пустой файл — из папки. Так ушли `модель-лишние-поля.md` (#484),
`разбор-markdown.md` (#486) и `фронтенд-migrate-on-touch.md` (#493); логи и
замок на `ReasoningStreamTest` закрыл #482.
