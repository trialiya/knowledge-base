# Feature Guides

Руководства пользователя по основным возможностям Knowledge Base.

Приложение состоит из **трёх основных вкладок** (Чат, База знаний, Файлы) и **двух служебных панелей** (Настройки и Администрирование).

## Основные вкладки

- **[Чат — руководство пользователя](чат-руководство-пользователя.md)** — взаимодействие с AI, создание и редактирование документов через диалог
- **[База знаний — руководство пользователя](база-знаний-руководство-пользователя.md)** — навигация по документам, просмотр, редактирование, создание, перемещение
- **Файлы** — просмотр файлов репозитория, поиск, интеграция с чатом

## Поиск и фильтры

- **[Поиск — руководство пользователя](поиск-руководство-пользователя.md)** — глобальный поиск по базе знаний (keyword, semantic, hybrid режимы)

## Специальные возможности

- **[История описания документа](история-описания-документа.md)** — просмотр изменений, сравнение версий, восстановление
- **[Экспорт документов](экспорт-документов.md)** — выгрузка базы знаний в файловую систему (API)

## Служебные панели

- **[Настройки](настройки-руководство-пользователя.md)** — модели AI, параметры поиска, инструменты
- **[Администрирование](администрирование-руководство-пользователя.md)** — система, статус БД, переиндексация, экспорт
