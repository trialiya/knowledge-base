# 1.1.0

Что вошло в релиз и что осталось закрыть до тега `v1.1.0`. Состав релиза для
тех, кто ставит приложение, — по-английски в `CHANGELOG.md`; что обновление
требует от того, кто его делает, — в `UPDATING.md`. Здесь внутренняя сторона
выпуска.

Выпуск идёт так же, как 1.0.0: кандидатов ставят не на той машине, где
собирали, и только потом — тег `v1.1.0`. Что найдёт кандидат, получает свою
секцию в `CHANGELOG.md` под следующим номером.

- `1.1.0-RC1` (25.09) — состав релиза.
- `1.1.0-RC2` (27.09) — исправления по ревью #412–#430 (#431, #432), MCP после
  рестарта сервера (#429), разбор секций markdown (#436), и то, что влили
  рядом: вкладка «Структура» и детали коммита в «Файлах» (#430, #435, #438,
  #439, #441, #443), запись в документ без повторного чтения (#434, #442),
  «Изменённые документы» в чате (#440).
- `1.1.0-RC3` (28.09) — кэш промпта: рассуждения модели хранятся и
  возвращаются ей (#455, #456), описание вложения замораживается при отправке
  (#457); ответы инструментов без пустых полей (#453, #454); потерянные правки
  в базе знаний и первое сообщение нового чата (#445, #446, #449); вопрос без
  ответа (#451), контекст по обращениям (#452), логи вызовов (#460).
- `1.1.0` (30.09) — всё из трёх кандидатов и то, что влили после RC3: поиск
  файлов по имени и перенос длинных строк в выдаче (#467, эталоны — #471),
  повторное сжатие чата больше не теряет прежние запросы (#470).

## 0. Что сделано

- Версия `1.1.0-RC1` в `build.gradle`, `backend/build.gradle`,
  `frontend/package.json` и в строке «Current version» в README.
- `CHANGELOG.md`: секция `[Unreleased]` закрыта номером `1.1.0-RC1`. В неё
  добавлены изменения, влитые после того, как секция была собрана (#416, #418,
  #420, #421–#424, #427), запись #416 перенесена из отдельного второго
  «Fixed» к остальным. Раздел «Upgrading» собран из `UPDATING.md`, как
  «Changed since the pre-release `main`» у 1.0.0-RC1.
- `UPDATING.md`: раздел `## Unreleased` закрыт номером `1.1.0-RC1` — четыре
  записи: название чата вместо `recordChatInsights`, запуск скриптов из
  манифеста и вложений, MCP вне старта приложения, `getUncommittedChanges` без
  untracked-файлов.
- README и `docs/проект/введение.md`: в списке возможностей — тёмная тема,
  сохранённые скрипты, `/compact-1`, MCP, не мешающий старту.
- Документация под каждую фичу обновлялась в её собственном PR; перед
  выпуском сверено, что упоминаний `recordChatInsights` в `docs/проект/` и
  `docs/features/` не осталось (только в `docs/todo/`, это проработка).

- **RC2:** версия `1.1.0-RC2` в тех же четырёх местах; секция
  `[1.1.0-RC2]` в `CHANGELOG.md` со своим «Upgrading»; раздел `## Unreleased`
  в `UPDATING.md` закрыт номером `1.1.0-RC2` (три записи: пути секций под
  повторным заголовком, неизвестный проект в расписании скриптов, имена
  MCP-инструментов). В README у панели «Файлы» — структура файла и детали
  коммита. Документация под каждую фичу обновлена в её PR.
- **RC3:** версия `1.1.0-RC3` в тех же четырёх местах; секция
  `[1.1.0-RC3]` в `CHANGELOG.md` со своим «Upgrading»; раздел `## Unreleased`
  в `UPDATING.md` закрыт номером `1.1.0-RC3` (три записи: `replay-reasoning`
  по умолчанию, пустые поля в ответах git API и API документов). В
  руководстве по чату — кнопка «Получить ответ» вместо «Повторить» и
  подсказка о контексте у промежуточного сегмента ответа.
- **1.1.0:** версия `1.1.0` в тех же четырёх местах, строка «Current version»
  в README без оговорки про кандидата; секция `[1.1.0]` в `CHANGELOG.md` —
  #467 и #470 поверх кандидатов; в `UPDATING.md` раздел `## 1.1.0` — от RC3
  обновление ничего не требует, от 1.0.0 — три раздела кандидатов по порядку.
  В руководстве по поиску — поиск файлов по имени и перенос длинных строк
  (#467 обновил только `docs/проект/`). После RC3 проверены все влитые PR:
  критичных ошибок нет. Ежедневная визуальная сборка на `main` падала между
  #467 и #471 — эталоны карточек поиска, #471 их переснял. Не в CHANGELOG —
  пользователь этого не видит: мутационные тесты PIT (#462), замена
  устаревших API в тестах и контроллере (#463, #464), подтверждение прогонов
  CI на PR (#468, #469), эталоны харнесса (#471).
