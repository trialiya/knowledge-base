  `node_modules/` в любом каталоге, не только во `frontend/`.

  реально лежит на диске (были ссылки на несуществующие папки, дубль и
  пропущенные документы).
- Из `docs/todo/` убраны завершённые планы и описания снятого кода.
- Заведён `CHANGELOG.md` (по-английски, как и README) с описанием состава
  1.0.0-RC1 и раздела «Known limitations»; README актуализирован под него —
  добавлены разделы про git-команды пользователя, `runScript`, несколько
  репозиториев, сжатие контекста и i18n, поправлены категории поиска, ключ
  `kb.projects[].path` вместо устаревшего `kb.git.project-path` и предупреждение

## 2. Желательное, но не блокирующее

- **Опечатка в имени миграции** — `V2026.05.22__system_documecnts.sql`.
  Переименование меняет `description` в `flyway_schema_history`, поэтому
  безопасное окно для него — до первой публичной установки, то есть именно
  сейчас. Иначе останется навсегда.
- **Крупные файлы под разделение** (правило «~500 строк кода на бэкенде,
  ~300 на фронте» из `CLAUDE.md`): `GitService` (894), `DocumentFunction` (681),
  `DocumentService` (675), `icons/index.jsx` (555), `useKnowledgeBase.js` (471),
  `ChatWindow.jsx` (469). Делятся по правилу «migrate on touch», а не отдельным
  проходом перед релизом — рефакторинг на RC добавляет риска больше, чем снимает.
- **Squash миграций** (29 Postgres / 21 H2) в один baseline. Соблазнительно
  перед 1.0.0, но ломает любую уже развёрнутую инсталляцию — делать только если
  таких нет, и отдельным PR.

## 3. Проверено и трогать не нужно

- Секретов в репозитории нет: `sk-xxxx…` в `docker/example.env` и
  `run/application.yaml` — плейсхолдеры.
- `TODO`/`FIXME`/`@Deprecated` в коде отсутствуют.
- Нет неиспользуемых модулей фронта, неимпортированных CSS и «мёртвых» классов
  бэкенда (кандидаты из поиска — бины Spring).
- Локали `en`/`ru` совпадают ключ в ключ; расхождение `_few`/`_many` — это
  правила множественного числа русского, а не пропуск.
- `billing` в примерах конфигурации — сквозной пример второго проекта, он же
  в документации; это не утечка чужого имени.
