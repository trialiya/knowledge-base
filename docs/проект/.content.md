# Документация проекта Knowledge Base

Архитектурные документы и справочники для разработчиков, администраторов и интеграторов.

## Структура документации

### 📌 Начните отсюда

- **[Введение](введение.md)** — обзор проекта, ключевые возможности, технологический стек, быстрый старт
- **[Архитектура](архитектура.md)** — общая схема системы, слои (Controller, Service, AI, Repository), компоненты

### 🏗️ Архитектура и дизайн

- **[Обзор чат-системы](обзор-чат-системы.md)** — как работает чат: стриминг ответов, сохранение истории, MCP-интеграция, инструменты AI
- **[Архитектура и реализация поиска](архитектура-и-реализация-поиска.md)** — гибридный поиск (keyword + semantic), эмбеддинги, pgvector, чанкинг
- **[Фронтенд — обзор архитектуры](фронтенд-обзор-архитектуры.md)** — React 19, компоненты, потоки данных, хуки, работа с SSE
- **[Модели данных](модели-данных/.content.md)** — сущности и DTO по группам, с диаграммами ERD

### 📖 API и инструменты

- **[API Reference](api-reference.md)** — эндпоинты по контроллерам: документы, чаты, вложения, git и git-команды, фразы, настройки, пробный запуск скрипта, системная информация
- **[AI-инструменты](ai-инструменты.md)** — инструменты Spring AI по функциям: Document, Git, GitEdit, Attachment, Topic, MessageLookup, SearchAgent, Script, Skill

### 🚀 Установка и запуск

- **[Руководство по установке](руководство-по-установке.md)** — пошаговая инструкция развёртывания (PostgreSQL, Docker Compose, переменные окружения)
- **[Быстрый старт с H2 (standalone)](быстрый-старт-с-h2-standalone.md)** — 3 команды для запуска без PostgreSQL и AI-ключа (для локальной разработки)
- **[Конфигурация](конфигурация.md)** — все параметры `application.yaml`, переменные окружения, профили (h2, postgres), настройки поиска и чата

### 👨‍💻 Разработка

- **[Разработка и контрибьюция](разработка-и-контрибьюция.md)** — рабочий процесс, запуск тестов, стиль кода, PR процесс
- **[GitHub Workflows](github-workflows.md)** — CI/CD конфигурация (Dependabot, PR-тесты, daily-build, coverage)
- **[Нативный образ (GraalVM Native Image)](нативный-образ-graalvm.md)** — экспериментальная сборка: требования к GraalVM, метаданные рефлексии, ограничения (выключена по умолчанию)
