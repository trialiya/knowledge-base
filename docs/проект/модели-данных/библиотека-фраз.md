## Сущность

### PhraseEntity
Таблица: `phrase`. Хранит одну фразу из библиотеки. Глобальная — приложение однопользовательское, библиотека общая.

| Поле | Тип | Описание |
|---|---|---|
| `id` | `@Nullable Long` (PK) | Автоинкремент |
| `category` | `String` | Категория (свободная строка, нет отдельного справочника) |
| `label` | `String` | Название фразы |
| `text` | `String` | Текст фразы |
| `position` | `int` | Порядок внутри категории |
| `enabled` | `boolean` | Включена ли |
| `favorite` | `boolean` | В избранном |
| `createdAt` | `Instant` | Создана |
| `updatedAt` | `Instant` | Обновлена |

`record` — иммутабельный. Мутации через копирующие методы:
- `withEnabled(boolean)` — переключить enabled
- `withPosition(int)` — переместить на новую позицию
- `withFavorite(boolean)` — переключить избранное

---

## DTO

### Phrase
API-представление фразы. `record(Long id, String category, String label, String text, int position, boolean enabled, boolean favorite)`. Фабрика `Phrase.from(PhraseEntity)`.

### PhraseRequest
Тело создания/обновления. `record(String category, String label, String text, @Nullable Boolean enabled)`. `category`, `label`, `text` — обязательные, тримятся и валидируются в `PhraseService`. `enabled` — опционально (null → true). Флаг `favorite` не входит — переключается отдельным эндпоинтом.

### MovePhraseRequest
Тело перемещения. `record(int position)`. `position` — целевой слот (реальная позиция соседа, не порядковый индекс). Допускаются пропуски. Конвенция windowed-shift как у перемещения документов.
