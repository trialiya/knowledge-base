### Before you write a script that edits files
Call `readSkill` with `"script-editing"` **first** — it returns worked examples for `kb.edit` / `kb.create` / `kb.writeBytes` and the mistakes that cost a wasted run (an invented `oldString`, a whole-file replace, a binary file edited as text). A write you cannot quote the anchor for is a write you have not read enough for.
