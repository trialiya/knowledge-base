# AGENTS.md

Правила для агентов, работающих в этом репозитории. Соглашения проекта — сборка,
тесты и правила, действующие везде — в `CLAUDE.md`; подробные конвенции лежат
рядом с кодом, который они описывают, в `.claude/rules/` (бэкенд, JSX, CSS), а
окружение сборки и визуальные проверки — в скиллах `.claude/skills/`. Здесь
только две привычки, которые иначе теряются от сессии к сессии.

## Запуск проверок

Не собирай команду `gradle` руками — есть `run/test.sh` (на Windows
`run\test.bat` / `run\test.ps1`). Он сам решает то, что иначе приходится
вспоминать каждый раз: системный Gradle или `./gradlew`, нужен ли init-скрипт
для JDK 21, поднят ли `dockerd` для Testcontainers.

Без аргументов — быстрая пара (unit + front), перед пул-реквестом — `pre-pr`.
Полный список сьют, правила проброса аргументов после `--` и переменные
окружения — в шапке самого скрипта: она лежит рядом с кодом и не может от него
отстать, поэтому дублировать её сюда не надо.

## Визуальные проверки

Перед ручной проверкой компонента прочитай `frontend/tests/visual/cases.yaml` —
там уже описаны сценарии и данные для проверенных компонентов, фикстуры рядом в
`fixtures/`. Правила ведения реестра (как заводить кейс, почему нельзя
переименовывать `id`, что можно класть в фикстуры) — в шапке самого `cases.yaml`.
